# 재현성 검토 워크벤치

프로젝트 → 검증·문헌 → 재현성 점검에서 사용한다. 기존 기록 준비도 점검과 함께 다음을 제공한다.

- 필수 누락 항목부터 최대 4개의 다음 조치와 해당 화면 바로가기.
- 원본·재실험 데이터 선택, 평균차 절댓값 허용차, 최소 유효 반복수, 선택적 CV 상한, 재실험 절차 및 기준 근거 기록. 저장된 원본 조건을 바탕으로 계획 초안을 만들 수 있다. 연구자가 수정·확인할 초안이며 독립 실험을 수행했다는 뜻은 아니다.
- 계획·기준을 저장한 뒤 검토 실행. 수정 후에는 다시 저장해야 한다. 저장 시각은 남지만 데이터를 보기 전에 정한 사전등록임을 보장하지 않는다.
- 서로 다른 자료, 정확한 측정량·단위, 독립 수행 및 조건에 대한 연구자 확인, 측정 당시 프로토콜 일치, 제외 사유, 반복수, 평균차 및 선택적 CV 점검.
- 근거가 부족하면 ‘판정 보류’, 근거 확인 후 수치 기준 초과 시 ‘입력 기준 미충족’, 모두 만족하면 ‘입력 기준 충족’. 이는 지정한 기준에 관한 판정이며 일반적인 재현 성공·통계적 동등성 판정이 아니다.
- 검토 당시 두 데이터셋의 원자료·제외 이유·조건·프로토콜과 계획·판정 근거를 스냅샷으로 저장. 프로젝트당 최대 30개 이력. 이후 데이터 수정과 과거 판정을 구분한다.
- Markdown 보고서 및 근거 JSON 다운로드. 전체 연구 보고서와 연구 기록 JSON에도 이력이 포함된다.

CV는 표본 표준편차 / |평균| × 100이다. 평균 0이나 산포 계산 불가 시 CV는 미확인이다. 평균차는 B−A이고 |B−A|가 입력 허용차 이하인지 비교한다. 반복수 기준은 독립 반복 수에 대한 사용자 기준이며 충분성 보장은 아니다. 측정 당시 프로토콜이 다르면 동일 조건 검토를 보류한다. 코드 실행·실물 실험·내용의 사실성 확인을 자동 수행하지 않는다. 사진의 픽셀을 독립 반복 실험으로 사용하지 않는다.

계획·검토 이력은 research_designs.design.reproduction에 저장하여 기존 사용자별 RLS를 적용한다. 새 DB 테이블이나 유료 AI 연결은 필요하지 않다.
