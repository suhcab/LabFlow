# 연구 기간·연구 일지·용어 도움말

## 전체 달력

연구 현황에서 설정한 시작일과 마감일을 모두 포함해 매주 날짜 열 아래에 기간 막대를 표시한다. 달·주 경계에서 막대를 잘라 표시하고 화살표로 이어짐을 알린다. 같은 기간의 여러 프로젝트는 별도 줄로 표시하며 프로젝트 필터도 적용한다. 날짜를 누르면 해당 날짜에 진행하는 연구 목록과 개별 일정을 확인한다. 막대를 누르면 프로젝트 일정으로 이동한다. 시작일 또는 마감일이 없으면 기간을 추정하지 않는다. 기존 마감 일정 표시는 유지한다.

## 연구 일지

프로젝트 → 연구 관리 → 연구 일지에서 실험 날짜, 오늘 한 일(필수), 생긴 문제, 다음에 할 일을 입력한다. 항목별 최대 2,000자이고 한 프로젝트에 날짜당 한 편을 저장한다. 같은 날짜의 기록은 목록에서 열어 수정한다. 새 날짜 기록과 변경 취소를 제공하며 저장한 일지 전체를 Markdown 파일로 내보낼 수 있다.

기존 research_designs.design의 journal_entries에 저장하여 원래의 설계·사진·참고문헌·재현성 기록을 보존한다. 추가 DB 마이그레이션은 필요하지 않다. 프로젝트 팀원 RLS, revision 충돌 차단, 자동 수정 이력을 그대로 적용한다. 다른 사람이 설계나 분석 기록을 먼저 저장한 경우에도 조용히 덮어쓰지 않으며, 입력 내용을 복사해 보관한 뒤 변경 취소와 최신 내용 불러오기를 사용한다.

## 용어 도움말

데이터·불확도의 장비 분해능 d, 포함인자 k 옆 물음표를 클릭/키보드로 열면 뜻·입력 단위·숫자 예시를 표시한다. 결과 카드의 s, uA, uB, uc, U도 같은 방식으로 설명한다. 도움말 버튼은 입력 label 밖에 배치해 폼 입력 초점과 분리한다.

분해능의 반올림 범위 ±d/2에 대한 균등분포 가정과 d/√12, 독립 성분의 제곱합, U=k·uc를 설명한다. d=0이 오차 없음이나 k=2가 모든 상황의 95%라는 오해를 피한다. 참고: [NIST B형 평가](https://physics.nist.gov/cuu/Uncertainty/typeb.html), [NIST 확장불확도](https://physics.nist.gov/cuu/Uncertainty/coverage.html).

## 검증

TypeScript, 변경 파일 Oxlint, Vercel 빌드 및 Node 테스트 32개 통과. 기간 테스트에는 시작/마감일 포함, 경계 밖 제외, 날짜 미정/역전, 주·달 경계, 단일 날짜, 겹치는 기간, 윤일을 포함한다.
