# 연구 도구의 계산과 해석

## 계산 범위

한 데이터셋은 동일 조건에서 같은 측정량을 독립 반복 측정한 원자료입니다. 서로 다른 조건의 값을 한 데이터셋에 섞어 평균 내지 않습니다. 무차원 단위는 `1`로 입력합니다.

- 평균: 포함된 원자료 합계 / n
- 표본 표준편차: s = √[Σ(xᵢ−평균)² / (n−1)]
- 평균의 Type A 표준불확도: uA = s / √n
- 분해능 d의 반올림 오차가 ±d/2 범위의 균등분포라는 가정: uB = d / √12
- 두 성분의 독립성을 가정: uc = √(uA² + uB²)
- 확장불확도: U = k·uc

n<2에서는 s, uA, uc, U를 계산하지 않습니다. 분해능 0은 분해능 성분을 추가하지 않았다는 뜻입니다. 실제 교정, 환경, 계통 효과, 상관 등을 자동 평가한 전체 불확도 예산이 아닙니다. 포함인자 2가 언제나 95% 신뢰수준을 뜻하지는 않습니다. 표본 수, 분포와 유효 자유도 등을 추가 검토해야 합니다.

근거: [JCGM GUM 4장](https://www.iso.org/sites/JCGM/GUM/JCGM100/C045315e-html/C045315e_FILES/MAIN_C045315e/04_e.html), [NIST Type B 불확도 평가](https://physics.nist.gov/cuu/Uncertainty/typeb.html), [NIST 표준·확장불확도](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc57.htm).

## 원자료와 비교

이상값을 자동 삭제하지 않습니다. 제외할 값에는 이유를 남기며 CSV와 JSON은 제외 전 원자료를 보존합니다. 측정값 자체를 수정하면 제외 인덱스가 잘못 적용되지 않도록 제외 표시를 초기화합니다. 데이터셋 보관은 복원할 수 있습니다.

비교는 측정량과 단위 문자열이 같은 두 자료에만 허용하며 단위를 자동 변환하지 않습니다. B−A 평균 차이와 A 평균 절댓값에 대한 변화율을 계산합니다. 두 평균 추정이 독립이라는 가정하에 차이의 표준불확도를 RSS로 표시합니다. 통계적 유의성이나 재현 성공을 자동 판정하지 않습니다.

## 재현성 점검

연구 질문·변수·통제·환경·프로토콜·원자료·반복·제외 기준·출처 등 기록 항목의 존재를 점검합니다. 시뮬레이션은 코드 버전과 시드를 별도로 확인합니다. 데이터셋마다 측정 당시 프로토콜 스냅샷을 저장하고 현재 프로토콜과 차이가 있으면 표시합니다.

기록 준비도는 체크된 기록 항목의 비율이며 실제 재실험 성공 확률, 연구의 타당성 또는 AI의 검증 결과가 아닙니다. 사용자가 입력한 내용의 사실성, 모델 실행과 독립 재현은 별도 검증해야 합니다.
