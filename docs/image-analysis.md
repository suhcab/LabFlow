# 사진 수치 분석

프로젝트 → 사진 분석에서 PNG·JPEG·WebP를 연다. 파일은 15MB, 디코딩된 크기는 1,600만 픽셀 이하로 제한한다. 원본은 브라우저 안에서 처리하며 서버에 업로드하지 않는다. 분석 결과 저장 시 파일명, SHA-256 지문, 이미지 크기, 좌표, 수치, 기준 길이 및 메모를 기존 연구 설계 JSON에 저장한다. 소유자 접근 정책을 그대로 적용한다. 프로젝트당 최대 30개 기록을 저장한다.

1. 처음에는 전체 사진이 영역 A이다. 영역 A/B 버튼을 누르고 사진에서 사각형의 두 모서리를 차례로 누른다. 정밀 좌표 입력으로 동일한 작업을 키보드로 수행할 수 있다.
2. 밝기 기준(0–255)을 지정하고 영역 수치 계산을 누른다. 영역별 RGB 평균, 밝기 평균, 히스토그램, 기준 이상 픽셀 수와 면적 비율을 표시한다. B가 있으면 B−A 밝기 차이, A 대비 변화율 및 면적 비율의 %p 차이를 표시한다. A 밝기가 0이면 상대 변화율은 계산하지 않는다.
3. 기준 길이 버튼으로 실제 길이를 아는 두 점을 정한 뒤 실제 길이와 단위를 입력한다. 측정 길이 버튼으로 다른 두 점을 지정한다. 측정 픽셀 거리 ÷ 기준 픽셀 거리 × 실제 기준 길이로 환산한다. 기준이 없으면 픽셀 거리만 남긴다.
4. 촬영 조건·해석 메모와 제목을 작성하고 프로젝트에 저장한다. 결과 JSON 또는 연구 기록 JSON·Markdown 보고서로 내보낼 수 있다. 원본은 별도로 보관한다.
5. 재접속 후 저장한 수치를 확인한다. 같은 원본을 열고 저장 기록의 ‘동일 원본에 좌표 복원’을 누르면 SHA-256 일치 확인 후 영역·기준·측정선·기준값을 복원한다. 다른 파일이면 복원하지 않는다.

## 계산 및 해석

브라우저 디코딩 RGB(0–255)를 사용한다. 투명 픽셀은 흰 배경과 알파 합성 후 계산한다. 밝기는 인코딩 RGB의 0.2126R+0.7152G+0.0722B 가중 합으로, 선형 광량이나 교정된 휘도가 아니다. 선택 영역 시작은 내림, 끝은 올림하여 정수 픽셀 경계를 정하고 사진 범위로 제한한다. 밝기 기준과 같은 픽셀도 포함한다. 히스토그램은 밝기를 반올림해 256개 구간에 누적한다. 표시된 오버레이는 계산 픽셀에 포함하지 않는다.

동일 조명·노출·화이트밸런스·배경 조건이 중요하다. 임계값만으로 세포·집락·사물의 정체를 인식하거나 농도를 결정하지 않는다. 픽셀 수는 독립 반복 실험 수가 아니므로 기존 데이터셋의 반복 측정 통계로 자동 변환하지 않는다. 길이는 같은 평면의 균일 축척을 가정한다. 원근·렌즈 왜곡·선택 오차·측정불확도를 자동 보정하지 않는다.

단위 테스트는 ROI, 알파 합성, 밝기 경계값, 빈 영역 및 범위 거부, 길이 환산, 영역 간 차이를 검증한다.
