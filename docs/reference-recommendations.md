# 참고문헌 추천 방식

프로젝트 → 참고문헌 탭에서 이용한다. 유료 AI API나 외부 자동 검색 API 없이 내장 문헌 16개의 분야·한국어/영어 태그를 프로젝트명, 주제, 저장한 연구 질문·변수와 대조한다. 키워드 1개당 10점, 분야 일치 3점, 공통 방법 자료 1점으로 정렬한다. 점수는 학술적 품질·인용 수·관련성 확률이 아니다. 결과 카드에 일치 키워드 또는 배경 자료라는 추천 이유를 표시한다.

분야 필터·검색·저장한 문헌 필터를 지원한다. 프로젝트에 저장하면 기존 연구 설계의 data_source에 인용문을 덧붙여 Supabase에 보존한다. 기존 원자료 메모는 유지하고 동일 URL은 중복 추가하지 않는다. 연구 현황에서 인용문을 수정·제거할 수 있으며 보고서와 연구 기록 JSON에도 포함된다. 저장 목록 TXT, 간략 BibTeX, 개별 인용 복사를 지원한다.

내장 문헌만으로 연구 범위를 포괄할 수 없으므로 Google Scholar 검색 링크를 함께 제공한다. 자동 전송 없이 사용자가 링크를 누를 때 검색어(비어 있으면 프로젝트 주제)가 전달된다. 분야 일치만으로 추천한 자료는 연구 주제와 직접 관련되지 않을 수 있으며, 검색 결과가 없으면 이를 명확히 표시한다. 기관 자료·종설·조사 기사는 연구 논문과 구분한다. 오래된 대표 논문은 출발점으로 활용하고 후속 연구로 보완한다. 원문 이용료는 각 출판사 정책에 따른다.

## 출처 확인 (2026-10-27)

각 카드 URL/DOI가 출처다. NASA Glenn, NIST, IPCC, Nature, Science, Annual Reviews, APS/arXiv, NOAA 및 Project Euclid의 출판사·기관 페이지로 제목·발행 정보 확인. 예를 들어 F1 주제에는 [Katz의 종설](https://doi.org/10.1146/annurev.fluid.38.050304.092016)과 [NASA의 입문 자료](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/learn-about-aerodynamics/), 로봇 보행에는 [Hwangbo 등의 연구](https://doi.org/10.1126/scirobotics.aau5872)를 연결한다. 전체 초록·본문은 복제하지 않는다.

추천 순위·키워드 경계·기존 메모 유지·중복 방지·서지 링크를 Node 테스트로 검증한다. BibTeX는 간략 저자 표기를 포함하므로 제출 시 출판사의 전체 인용 정보로 보완해야 한다.
