운영 사이트: https://lab-flow-theta.vercel.app/

## 구현 및 실제 계정 확인

- 프로젝트 전용 탭: 연구 현황, 실험 프로토콜, 일정, 데이터·불확도, 실험 비교, 재현성 점검.
- 전체 달력: 모든 프로젝트 일정·마감일 표시, 프로젝트 필터, 해당 프로젝트 일정으로 이동. 모바일 메뉴는 선택 후 닫힘.
- 최근 프로젝트: 열어본 프로젝트 순서로 갱신하며 사용자별로 저장.
- 연구 설계·진행률·상태와 데이터셋을 Supabase에 저장. 재접속 후 저장 기록 확인.
- 직접 입력 및 CSV 열 선택 가져오기, 평균·표본 표준편차·평균의 표준불확도·분해능 성분·합성 및 확장불확도 계산.
- 원자료를 유지하는 제외값 처리: 이유 없이는 저장 차단. 보관한 데이터셋은 복원 가능.
- 동일 측정량·단위의 데이터셋 비교와 사용자가 정한 평균차 허용 기준 적용.
- 원자료 CSV, 연구 기록 JSON, 비교 근거 JSON, Markdown 보고서 다운로드 후 내용 확인.
- 기록 누락 시 보완 위치로 이동. 저장 전 이동에서는 계속 편집 또는 변경 취소 선택 확인.

## 합성 자료로 확인한 계산

`제출 전 점검 - 단진자 실험`은 기능 확인용 합성 자료이며 실제 실험 결과가 아니다.

- 조건 A 원자료: 1.40, 1.42, 1.41, 1.39, 9.99 s. 마지막 값은 고의 오류값이라는 이유를 남겨 제외했다. 분석 n=4, 평균 1.405 s, 표본 표준편차 약 0.012910 s.
- 분해능 0.01 s, k=2에서 A의 확장불확도 약 0.014142 s.
- CSV로 입력한 조건 B: 1.43, 1.42, 1.44, 1.41, 1.45 s. 평균 1.43 s.
- B−A 평균차 0.025 s. 허용차 0.05 s에서 충족, 0.01 s에서 초과 표시를 확인했다.
- A CSV 및 연구 JSON에 제외한 9.99와 제외 이유까지 남는 것을 확인했다.
- 기존 NCRC 프로젝트에는 자료가 없으므로 누락 항목을 표시하며, 예시 프로젝트 자료와 섞이지 않는다. 기존 연구 기록은 수정하지 않았다.

## 자동 및 DB 검증

- 연구 계산·파서·CSV·제외값·비교·프로토콜 연결·보관 관련 Node 테스트 13개 통과.
- TypeScript 검사, 변경한 연구 기능 파일의 lint, Vercel 빌드 통과. 전체 lint는 기존 공통 UI 파일의 접근성·React 규칙 오류 등이 남아 통과하지 않았다.
- Supabase SQL 검증: 소유자 읽기·쓰기 허용, 다른 사용자 조회 및 삽입 차단, 익명 권한 없음, 비수치 원자료 거부. 트랜잭션 롤백으로 점검 데이터 제거.
